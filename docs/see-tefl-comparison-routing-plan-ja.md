# Essential TEFL（Bangkok）とSEE TEFL（Chiang Mai）の比較・送客設計

調査日：2026年10月24日  
対象：既存のEssential TEFLレビュー、SEE TEFLレビュー、TEFL比較ハブと関連記事。この記事設計・リンク案は提案のみで、内部リンクは新たに変更していない。

## 編集方針

「どちらが上か」ではなく、読者が重視する都市、総予算、実地練習の内容、資格、就職支援の条件を基準に選べる構成にする。講座の案内や紹介報酬を、就職・ビザ・教員許可の保証と混同しない。紹介リンクを使うページでは、リンクの近くに報酬を受け取る可能性を開示する。

## 比較記事の構成案

1. 冒頭に「BangkokとChiang Mai、または資格・実地練習・総予算の何を優先するか」を選ぶ短い要約を置く。
2. 料金表を「標準120時間」「Level 5」「Internship」に分け、通貨と確認日を表示する。
3. 実地練習を回数・時間・対象学習者・観察とフィードバックに分ける。
4. 就職支援を通常コース、条件付き保証、別料金のInternshipに分離し、雇用条件と救済条件の確認欄を設ける。
5. 各都市の滞在費はひとつの平均額を断定せず、講座・30泊等の宿泊・食事・交通・渡航・初回給与までの期間を計算機で積み上げる。
6. 最後に「Bangkokで学校網やLevel 5を重視」「Chiang Maiの6回実習を重視」「いずれも、まず就労資格と雇用条件を確認」のように目的別に案内する。

## CTAと評価

- SEEレビューの紹介CTAは「現在の講座日程・料金・条件を公式ページで確認」の情報確認型とし、「申込」「割引」「保証付きで就職」など、意図しない約束を連想させない。
- CTAのそばで、紹介リンク経由の申込によりSiamTEFLが報酬を受け取る可能性を明示する。
- GA4では同意済み訪問だけで `affiliate_click` を送り、`provider=see_tefl`、`page_path`、`placement`、`destination=seetefl.com` を記録する。評価はSEE紹介リンクCTR、レビューから公式ページへの遷移、比較ハブ→SEEレビュー→紹介リンクの順次遷移で行い、`provider_outbound_click` と二重計上しない。
- 申込や報酬の成果データが提供されない限り、GA4のクリックだけで売上や申込率を断定しない。
